# Deployment Guide

Portals generated by `research-portal-studio` are 100% static, self-contained HTML/CSS/JavaScript bundles requiring no server runtime or database.

---

## 1. Local Preview Server

Preview the output directory using Python's built-in HTTP server:

```bash
python3 -m http.server 8080 --directory ./portal
```

Access the site at `http://localhost:8080`.

---

## 2. GitHub Pages Deployment

The generator creates `.nojekyll` in the root of the output directory to prevent GitHub Pages from ignoring directories or files starting with underscores (such as `_artifacts/`).

### Option A: Direct Repository Branch (`gh-pages`)
1. Compile your portal into a distribution folder:
   ```bash
   research-portal-studio --source . --output dist
   ```
2. Push the contents of `dist` to your repository's `gh-pages` branch:
   ```bash
   git subtree push --prefix dist origin gh-pages
   ```

### Option B: GitHub Actions Workflow
Create `.github/workflows/deploy-portal.yml`:
```yaml
name: Deploy Research Portal

on:
  push:
    branches: [main]

jobs:
  build-and-deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3

      - name: Set up Python
        uses: actions/setup-python@v4
        with:
          python-version: '3.11'

      - name: Install Dependencies
        run: pip install markdown beautifulsoup4 pyyaml

      - name: Compile Portal
        run: python3 /path/to/research-portal-studio/bin/research-portal-studio --source . --output ./public --config portal.yaml

      - name: Deploy to GitHub Pages
        uses: peaceiris/actions-gh-pages@v3
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./public
```

## 3. Vercel Static Deployment

Deploy instantly with the Vercel CLI:

```bash
cd ./portal
vercel deploy --temporary
```

To deploy directly to a production alias:
```bash
vercel --prod
```
